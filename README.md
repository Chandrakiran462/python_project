# Adult Census Income Dataset - Exploratory Data Analysis

## Project Overview

This project demonstrates Exploratory Data Analysis (EDA) and Data Cleaning techniques using the Adult Census Income dataset.

The objective of the project is to understand the dataset structure, perform statistical analysis, identify data quality issues, and apply various data cleaning techniques such as handling missing values, duplicate records, and outliers.

The project was developed using Python in Jupyter Notebook and covers both data exploration and preprocessing steps commonly used in real-world data analytics workflows.

---
